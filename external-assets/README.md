# External Assets

This folder stores small source files copied from external providers so implementation can start without re-discovering them.

Current contents:

- `a2d2/README.txt`
- `a2d2/cams_lidars.json`
- `a2d2/LICENSE.txt`

Large assets and model weights are staged under `data/raw/` instead of being committed.

Source inventory and download instructions are documented in `docs/specification/19-external-assets-inventory.md`.
